Basic Integration Rules

Power rule, exponentials, basic trig, and definite integrals — the foundation of every BC problem.

Key Formulas
\(\int x^n\,dx = \tfrac{x^{n+1}}{n+1}+C\) \(\int e^x\,dx = e^x+C\) \(\int \tfrac{1}{x}\,dx = \ln|x|+C\) \(\int \sin x\,dx = -\cos x+C\) \(\int \cos x\,dx = \sin x+C\)

u-Substitution

Reverse the chain rule. Spot the inside function, let \(u\) equal it, find \(du\), rewrite, integrate, back-substitute.

Strategy
Let \(u = g(x)\), so \(du = g'(x)\,dx\) \(\displaystyle\int f(g(x))\,g'(x)\,dx = \int f(u)\,du\)

Integration by Parts

Reverse the product rule. Use LIATE to choose \(u\): Logarithms, Inverse trig, Algebraic, Trig, Exponential.

Formula
\(\displaystyle\int u\,dv = uv - \int v\,du\)

Trig Integrals

Products and powers of sine, cosine, secant, and tangent. Lean on Pythagorean and half-angle identities.

Key Identities

Trigonometric Substitution

Eliminate radicals containing \(a^2-x^2\), \(a^2+x^2\), or \(x^2-a^2\) by a clever trig replacement.

Substitution Table
\(\sqrt{a^2-x^2}\): let \(x=a\sin\theta\) \(\sqrt{a^2+x^2}\): let \(x=a\tan\theta\) \(\sqrt{x^2-a^2}\): let \(x=a\sec\theta\)

Partial Fraction Decomposition

Break a rational function into simpler fractions whose integrals you already know.

Template
\(\dfrac{P(x)}{(x-a)(x-b)} = \dfrac{A}{x-a}+\dfrac{B}{x-b}\) \(\int\!\tfrac{1}{x-a}dx = \ln|x-a|+C\)

Improper Integrals

Infinite limits or discontinuous integrands — replace the bad endpoint with a limit and evaluate.

Definition
\(\displaystyle\int_a^\infty f\,dx = \lim_{t\to\infty}\int_a^t f\,dx\) \(\displaystyle\int_1^\infty \tfrac{1}{x^p}\,dx\) converges iff \(p>1\)

Quick Reference Sheet

All formulas you need for the BC exam in one place.

Power & Log

\(\int x^n\,dx = \tfrac{x^{n+1}}{n+1}+C\quad(n\neq-1)\)
\(\int \tfrac{1}{x}\,dx = \ln|x|+C\)
\(\int e^x\,dx = e^x+C\)
\(\int a^x\,dx = \tfrac{a^x}{\ln a}+C\)
\(\int \ln x\,dx = x\ln x - x+C\)

Basic Trig

\(\int \sin x\,dx = -\cos x+C\)
\(\int \cos x\,dx = \sin x+C\)
\(\int \sec^2\!x\,dx = \tan x+C\)
\(\int \csc^2\!x\,dx = -\cot x+C\)
\(\int \sec x\tan x\,dx = \sec x+C\)
\(\int \sec x\,dx = \ln|\sec x+\tan x|+C\)
\(\int \tan x\,dx = \ln|\sec x|+C\)

Inverse Trig

\(\int \tfrac{1}{\sqrt{1-x^2}}\,dx = \arcsin x+C\)
\(\int \tfrac{1}{1+x^2}\,dx = \arctan x+C\)
\(\int \tfrac{1}{x\sqrt{x^2-1}}\,dx = \text{arcsec}|x|+C\)

By Parts

\(\int u\,dv = uv - \int v\,du\)
LIATE: Log · Inv-trig · Alg · Trig · Exp

Trig Identities

\(\sin^2\!x = \tfrac{1-\cos 2x}{2}\)
\(\cos^2\!x = \tfrac{1+\cos 2x}{2}\)
\(\sin 2x = 2\sin x\cos x\)
\(\tan^2\!x = \sec^2\!x - 1\)
\(\cot^2\!x = \csc^2\!x - 1\)

Trig Sub

\(\sqrt{a^2-x^2}\Rightarrow x=a\sin\theta\)
\(\sqrt{a^2+x^2}\Rightarrow x=a\tan\theta\)
\(\sqrt{x^2-a^2}\Rightarrow x=a\sec\theta\)

Partial Fractions

\(\tfrac{P}{(x-a)(x-b)} = \tfrac{A}{x-a}+\tfrac{B}{x-b}\)
\(\tfrac{P}{(x-a)^2} = \tfrac{A}{x-a}+\tfrac{B}{(x-a)^2}\)
\(\tfrac{P}{x^2+bx+c} = \tfrac{Ax+B}{x^2+bx+c}\)

Improper Integrals

\(\int_1^\infty x^{-p}dx\) conv. iff \(p>1\)
\(\int_0^1 x^{-p}dx\) conv. iff \(p < 1\)
\(\int_{-\infty}^\infty e^{-x^2}dx = \sqrt{\pi}\)
